# data-manipulation-python

Learning-focused notebooks for Python data manipulation, centered on **NumPy** and **Pandas**.

## Clone

```bash
git clone https://github.com/<YOUR_USERNAME>/data-manipulation-python.git
cd data-manipulation-python
```

## Folders

- [Numpy-Learn/](Numpy-Learn/) — see [Numpy-Learn/README.md](Numpy-Learn/README.md)
- [Pandas-Learn/](Pandas-Learn/) — see [Pandas-Learn/README.md](Pandas-Learn/README.md)

## Quick start

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install numpy pandas jupyter
jupyter lab
```

On Windows (PowerShell):

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install numpy pandas jupyter
jupyter lab
```
